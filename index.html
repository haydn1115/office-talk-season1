      Switch it.

      문법은 맞지만 번역투로 들리는 문장입니다. 표시된 표현을 넣어 원어민이 쓸 문장으로 바꿔 쓰세요.

      If we were to…, would you…?

      If we order…, will you…? 는 확정처럼 들립니다. 아래 두 군데만 바꾸면 ‘만약 ~한다면’이라는 부담 없는 제안이 됩니다.

      1. if 절의 동사 앞에 were to를 넣습니다.If we order → If we were to order
      2. will은 would로, can은 could로 바꿉니다.will you give → would you give
      3. 나머지 단어는 그대로 둡니다.
      If we order 500 units, will you give us 10% off?If we were to order 500 units, would you give us 10% off?
